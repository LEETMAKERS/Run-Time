# Run Time

Play two games with four colours: **Red, Blue, Green, and Brown**.
Test your reactions in **Speed Sprint** or challenge your memory in **Memory Quest**.

## How to play

- Flip **MODE** in the menu to choose a game.
- Press and release **START** to begin.
- Press the matching colour button to answer. Release all colour buttons before your next answer.
- Press **START** during a game to return to the menu.

## Speed Sprint

You have **15 seconds** to match as many displayed colours as possible.

- Each correct answer earns **1 point**.
- Every **5 consecutive correct answers** earns **2 bonus points**.
- A wrong answer or pressing multiple colours at once earns no points and resets your streak.

When time runs out, see your score, correct answers, total attempts, and session best.

## Memory Quest

Watch the colour sequence. When **YOUR TURN** appears, repeat it in the same order.

For example: **Red → Brown → Blue** means press Red, then Brown, then Blue,
releasing each button between presses.

### Every level gets harder

- Level 1 starts with **3 colours**.
- Each new level adds **one colour** to the same sequence.
- Colours appear faster, with shorter gaps between them.
- You get less time to enter each answer.
- Complete all **40 levels** to become **Memory Master**!

The same colour can appear twice in a row. Each appearance needs a separate press.

### Lives and second chances

You start with **3 lives**. A wrong answer, pressing multiple colours at once,
or running out of time costs one life. If you have lives left, watch the same
sequence again and retry the level.

Every **5 completed levels** restores **1 life**, up to a maximum of 3.
The game ends when you run out of lives or complete all 40 levels.

Release buttons promptly: holding one does not repeat an answer or pause the timer.

## Beat your best

Try to beat your best Speed Sprint score and highest completed Memory Quest level.
Records last for the current session and clear when the game is reset or powered off.
